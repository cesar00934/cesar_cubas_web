Sitio estático optimizado para Vercel. No necesita base de datos ni dependencias.

## Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel: **Add New → Project → Import Git Repository**.
3. Framework preset: **Other**. No hace falta comando de build.
4. Deploy.
5. Si la URL final NO es `https://desarroladordesofwareperu.vercel.app`, reemplaza esa URL en:
   - `robots.txt`
   - `sitemap.xml`
   - las etiquetas `canonical`, `og:url` y JSON-LD de los HTML.

## SEO después de publicar

- Registra el dominio en Google Search Console.
- Envía `/sitemap.xml`.
- Solicita indexación de la home y páginas de servicios.
- Si compras dominio propio, úsalo como principal y reemplaza la URL del sitemap/canonicals.
- Completa un Perfil de Empresa de Google solo si corresponde a una actividad real y verificable.
